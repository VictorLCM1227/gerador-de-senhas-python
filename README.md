# Gerador de Senhas

## Sobre o projeto

Uma aplicação de terminal capaz de gerar senhas aleatórias de acordo com as características escolhidas pelo usuário.

A ideia é permitir que o usuário defina o tamanho da senha e quais tipos de caracteres deseja utilizar.

## Objetivo

Praticar Python através da criação de uma aplicação que trabalhe com geração aleatória, strings, funções, entrada de dados e manipulação de caracteres.

## Funcionamento planejado

1. O programa apresenta as opções de configuração.
2. O usuário informa o tamanho desejado.
3. O usuário escolhe os tipos de caracteres.
4. O programa cria um conjunto de caracteres.
5. Caracteres são selecionados aleatoriamente.
6. A senha é montada.
7. A senha gerada é exibida.
8. O usuário pode gerar outra senha ou encerrar o programa.
